## Problem

Autonomous aerial systems often need to make decisions from visual and semantic information while operating under strict timing and safety constraints. A useful safety signal must be connected to the current task, not treated as a generic label detached from the planner.

## Motivation

TC-SafePlan studies how task-conditioned semantic monitoring can inform planning when model inference has non-negligible latency. The project is designed around the distinction between recognizing a potential hazard and acting on that recognition in time.

## Method

The framework combines task-conditioned semantic safety monitoring with latency-aware planning. The public project description intentionally stops at the research direction; implementation details, evaluation results, and resources will be added when they are ready to share.
